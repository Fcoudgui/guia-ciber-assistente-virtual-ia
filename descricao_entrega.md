# Descricao para colar na DIO

Projeto: GuiaCiber - Assistente Virtual de Ciberseguranca

Criei um assistente virtual educacional para ajudar pessoas iniciantes a entender conceitos basicos de ciberseguranca. O assistente usa uma base de conhecimento local com topicos como phishing, senhas fortes, MFA, engenharia social, OSINT, metadados, DevSecOps e sistemas operacionais.

O projeto esta organizado em seis etapas: documentacao do agente, base de conhecimento, prompts, aplicacao funcional, avaliacao/metrica e pitch. A aplicacao possui uma versao em HTML, que pode ser aberta no navegador sem dependencias, e uma versao em Python para linha de comando.

O GuiaCiber responde de forma simples, evita inventar informacoes quando nao encontra contexto suficiente e recusa perguntas ofensivas, redirecionando para boas praticas defensivas.
