# Pitch do Projeto

## Problema

Pessoas iniciantes em tecnologia recebem muitos termos de ciberseguranca ao mesmo tempo: phishing, MFA, OSINT, metadados, engenharia social e DevSecOps. Sem uma orientacao simples, esses conceitos ficam abstratos e dificeis de aplicar.

## Solucao

O GuiaCiber e um assistente virtual educacional que responde perguntas basicas usando uma base de conhecimento organizada. Ele ajuda o usuario a entender riscos digitais e aplicar boas praticas no dia a dia.

## Publico

Estudantes, usuarios comuns e profissionais em inicio de carreira na area de tecnologia.

## Valor

- Explica conceitos de forma simples.
- Incentiva habitos seguros.
- Evita respostas inventadas.
- Mostra como uma IA pode usar uma base de conhecimento para apoiar uma tarefa real.

## Diferencial

O projeto e pequeno, transparente e facil de evoluir. A base de conhecimento pode crescer aos poucos, e a aplicacao pode futuramente ser integrada a uma API de IA generativa ou interface web.

## Conclusao

O GuiaCiber mostra uma primeira versao funcional de assistente virtual com IA orientado por conhecimento. Ele cumpre os seis passos do desafio: documentacao, base, prompts, aplicacao, avaliacao e pitch.
